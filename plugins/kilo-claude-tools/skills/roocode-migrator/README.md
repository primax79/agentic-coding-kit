# Roocode Migrator Skill

This Kilo skill helps automate the migration of legacy Roocode projects to modern web frameworks.

## Features

-   Analyzes Roocode projects to identify components and dependencies.
-   Generates a migration plan to guide the migration process.
-   Automates the conversion of Roocode-specific code to the target framework.
-   Provides tools to verify the correctness of the migrated code.

## Usage

To use this skill, invoke the Kilo agent with a request to migrate a Roocode project, for example:

```
kilo migrate my-roocode-project --to react
```

The skill will then guide you through the migration process.
